# Git & AWS EC2 Practice

This repository is created to practice using **Git and GitHub on an AWS EC2 instance**.

## About

The purpose of this repository is to learn the basics of Git, version control, and working with a remote Linux server using AWS EC2.

## What I am Learning

* Installing Git on an AWS EC2 instance
* Configuring Git
* Creating and managing Git repositories
* Tracking changes with Git
* Creating commits
* Working with GitHub repositories
* Connecting an EC2 instance to GitHub
* Pushing and pulling code
* Understanding branches
* Working with remote repositories

## Basic Git Commands

Some of the commands I am practicing:

```bash
git --version
git status
git init
git add .
git commit -m "commit message"
git log
git branch
git switch
git clone
git pull
git push
```

## Learning Workflow

The basic Git workflow I am following is:

```text
Create / Modify Files
        ↓
    git status
        ↓
      git add
        ↓
    git commit
        ↓
     git push
        ↓
      GitHub
```

## Environment

* **Cloud:** AWS
* **Server:** EC2
* **Operating System:** Linux
* **Version Control:** Git
* **Repository:** GitHub

## Goal

The goal of this repository is to build a strong understanding of Git and GitHub while gaining hands-on experience working with an AWS EC2 instance.
